# Project Screenshots Directory

Place your project screenshots here:

- `blood-link.png` -> For Blood Link
- `pocketflow.png` -> For PocketFlow
- `movie-discovery.png` -> For Movie Discovery App
- `student-portal.png` -> For Student Portal

Then update the `image` property in `src/data/portfolioData.js` to point to `/projects/your-file-name.png`.

If the `image` field is set to `null`, the website automatically displays an interactive, high-fidelity browser frame mockup designed specifically for that project.
